# Snake Game

Консольная игра «Змейка» на Python.

## Описание

Игрок управляет змейкой с помощью стрелок. Нужно собирать еду, зарабатывать очки и не врезаться в стены или собственное тело.

## Требования

- Windows.
- Python 3.12 или выше.
- [uv](https://docs.astral.sh/uv/).

## Установка

Откройте папку проекта в терминале:

```powershell
cd snake-game
```

Установите зависимости:

```powershell
uv sync
```

## Запуск

Для запуска со стандартными настройками выполните:

```powershell
uv run snake-game
```

По умолчанию: ширина поля — 20, высота — 12, скорость — 4.

Чтобы изменить настройки игры, укажите нужные параметры:

```powershell
uv run python snake.py --width 20 --height 15 --speed 8
```

Посмотреть все доступные аргументы можно с помощью команды:

```powershell
uv run python snake.py --help
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки | Изменить направление движения |
| `P` | Поставить игру на паузу или продолжить |
| `R` | Начать новую игру после проигрыша |
| `Q` | Выйти из игры |

## Правила игры

- За каждую съеденную еду даётся одно очко.
- После еды змейка становится длиннее на одну клетку.
- Каждые 5 очков открывается новый уровень.
- С каждым уровнем скорость змейки увеличивается.
- При столкновении со стеной или собственным телом игра заканчивается.
- Если на поле не осталось свободных клеток для еды, игра также заканчивается.

## Тестирование

Запустить тесты можно командой:

```powershell
uv run pytest
```

Проверяются движение и рост змейки, столкновения, поедание еды, начисление очков и появление еды на свободных клетках.

### Проверка кода

Проверка с помощью Ruff:

```powershell
uv run ruff check .
uv run ruff format --check .
```

Проверка типов с помощью Mypy:

```powershell
uv run mypy .
```
